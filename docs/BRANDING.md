# ECSTASY — Brand System

## Core

**Name:** ECSTASY

**Primary line:** `Private encounters. Public proof.`

**Secondary line:** `Private by default. Settled on Stellar.`

**Product category:** consent-first private-agreement protocol

## Positioning

ECSTASY is a Web3 primitive for bilateral agreements where private context stays off-chain and verifiable state transitions settle on Stellar.

## Voice

- provocative, not explicit;
- intimate, not romanticized;
- precise, not hype-heavy;
- cryptographic, not corporate;
- confident, not manipulative.

## UI mood

Dark, cinematic, premium, restrained. Think clandestine terminal + modern fintech rather than nightclub or casino.

These are product tokens, not a claim that final visual design is complete.

## Typography

Use a clean grotesk/sans for body copy and a restrained display face for the wordmark. Keep body text highly legible.

- EncounterCard

## Copy rules

Prefer:

- `Create encounter`
- `Review terms`
- `Consent`
- `Complete`
- `Settle`
- `Afterglow`

Avoid:

- `Bet`
- `Win/lose`
- `Hook up`
- `Secret lover`
- `Guaranteed trust`
- `Anonymous` unless the exact privacy property is technically true.
