# ECSTASY Protocol Notes

## Core invariant

An encounter is a bilateral agreement with a finite lifecycle.

## Proof semantics

A transaction proves that the contract accepted a particular state transition under its rules. It does not prove the truth of private off-chain statements.

## Privacy semantics

A hash is a commitment, not encryption. If the private terms can be guessed, enumerated, or obtained elsewhere, the hash does not provide confidentiality.

## Reputation semantics

Afterglow is participant-submitted feedback. It must not be marketed as objective safety, character, identity, or truth verification.
